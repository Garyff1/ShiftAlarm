# ShiftAlarm v1.0.0 Beta 1

这是 ShiftAlarm 的首个 GitHub 内部测试预发布版本。

> **签名警告：** APK 使用 Debug certificate 签名，仅供内部兼容性测试，不适合应用商店上架或长期公开分发。

## 版本信息

- Android minSdk 24
- Android targetSdk 36
- 包名 `com.shiftalarm.app`
- 已通过 185 项自动化测试
- 已通过 API 36 七条人工主流程

## 本次能力

- 班次规则、月历排班、临时调班和调班记录
- 精确系统闹钟、锁屏全屏提醒、停止、贪睡和超时释放
- 重启/时间/时区/权限恢复和 Direct Boot
- 自定义铃声导入、试听、分配、SHA-256 校验和系统铃声兜底

## 主要权限

应用会请求或引导用户配置精确闹钟、通知、全屏提醒，并使用前台媒体播放服务、开机恢复、Wake Lock 和振动。权限用途详见仓库 `PRIVACY.md`。

## 安装

1. 下载 `ShiftAlarm-v1.0.0-beta.1-universal.apk`。
2. 核对同页 `ShiftAlarm-v1.0.0-beta.1-SHA256.txt`。
3. 在 Android 中允许当前下载应用安装未知来源应用。
4. 已安装旧版时先尝试直接覆盖安装，以保留本地数据。

若提示签名不一致，**不要立即卸载旧版**。卸载通常会清除排班、设置和内部铃声；请先确认旧 APK 来源并备份可保留的信息。
